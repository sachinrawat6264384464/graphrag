# NexusAI Frontend

Enterprise SaaS Web Application for NexusAI (Hybrid RAG + GraphRAG Intelligence Platform).

## Stack
- Next.js 15 (App Router)
- React 19 + TypeScript (Strict Mode)
- Tailwind CSS
- Lucide Icons
- Designed following `DESIGN.md` guidelines (neutral tones, restrained blue accent, dark mode support).

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
